Crab Chess

A browser chess game where captures are settled by minigames. Play with a friend on the same keyboard or against a local Minimax opponent.

Built with JavaScript, Vite, and chess.js. AI search runs in a Web Worker, with automated tests for the game rules, search, and minigames.

Voces de la Plaza

A civic-education adventure built in Godot with team Latas for INEhack. Explore Villa Brisa, compare Mexican voter-participation data, and create a citizen poster to download as a PDF.

The web game requires a desktop computer, keyboard, WebGL 2, and WebAssembly. A Linux build is also included in the repository's submission package.
